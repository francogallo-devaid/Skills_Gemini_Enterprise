# Skills de Gemini Enterprise - Capacitación Entel

Bienvenido al repositorio de Skills de Gemini Enterprise. Este repositorio contiene una colección de herramientas (skills) diseñadas para potenciar el uso de Inteligencia Artificial en flujos de trabajo corporativos, presentaciones y redacción.

## Estructura del Repositorio

Cada skill está alojada en su propio directorio y contiene un archivo principal SKILL.md con las instrucciones del sistema, y opcionalmente carpetas con recursos adicionales.

- **/layout-planner**: Asesor de diseño para estructurar presentaciones de Entel Connect.
- **/presentation-compiler**: Compilador automático de presentaciones ejecutivas a .pptx.
- **/escribe-como-yo**: Asistente de redacción que adopta y replica tu estilo de escritura.
- **/generador-imagenes**: Generador de prompts para ilustraciones estilo "Corporate Memphis" con la paleta de Entel.

## Cómo usar estas skills

Para importar estas skills a tu entorno de Gemini Enterprise:
1. Clona o descarga este repositorio.
2. Sigue las instrucciones de la plataforma para importar el directorio o copiar el contenido de los archivos SKILL.md.
